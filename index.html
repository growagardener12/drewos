Calling service

Connect a free Supabase Realtime project to enable calls between devices.

DrewOS is hosted on GitHub Pages, so it needs a small realtime service to exchange call setup messages. Your video and audio stream peer-to-peer when the connection allows it.

One-time setup
  1. Create a project in Supabase.
  2. In SQL Editor, run the policy SQL below.
  3. Copy your project URL and publishable key from the project's Connect panel or Settings → API Keys.
  4. Paste them below, then choose Save & connect.
View SQL policies
drop policy if exists "DrewOS FaceTime receive broadcasts" on realtime.messages;
drop policy if exists "DrewOS FaceTime send broadcasts" on realtime.messages;

create policy "DrewOS FaceTime receive broadcasts"
on realtime.messages for select to anon, authenticated
using (extension = 'broadcast' and realtime.topic() like 'drewos-facetime-%');

create policy "DrewOS FaceTime send broadcasts"
on realtime.messages for insert to anon, authenticated
with check (extension = 'broadcast' and realtime.topic() like 'drewos-facetime-%');
Use only your project's public anon/publishable key, never a service_role or secret key. This browser stores the URL and public key locally.
ⓘ Calls need camera/microphone permission and a secure HTTPS page. Anyone with the invite link may attempt to join, so keep it private.
